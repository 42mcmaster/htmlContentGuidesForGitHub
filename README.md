# HTML Content Guides

Companion guides for the DIY tasks and projects in the `htmlCssJavaScript` course, html03 through html11.

Each task file in the course tells you **how** to build the page. The matching guide here tells you **what to put in it**: the page title, what each section and paragraph is about, which picture to find, what each caption, label, and button says. The HTML, CSS, and JavaScript are still yours to write.

## The site you build

All of the guides use one site, **The Shiny Log**, a website that keeps track of every shiny Pokémon you have found. Each unit adds to it:

| Unit | Guide | What it adds |
|---|---|---|
| html03 | `html03_ContentGuide.md` | The three pages: Home, About, Contact |
| html04 | `html04_ContentGuide.md` | A gallery of your own screenshots, a 20-second promo video, a comparison table |
| html05 | `html05_ContentGuide.md` | Restyle your About Me page (fills the empty spots first) |
| html06 | `html06_ContentGuide.md` | A card page with a fixed header and footer |
| html07 | `html07_ContentGuide.md` | A responsive gallery with 6+ photos |
| html08 | `html08_ContentGuide.md` | A Shiny Hunter Survey form |
| html09 | `html09_ContentGuide.md` | A Mad Libs page, then dark mode, hamburger nav, and form validation on the real site |
| html10 | `html10_ContentGuide.md` | Title tags, meta descriptions, the audit report, and publishing |
| html11 | `html11_ContentGuide.md` | The same content reworked for a Pokémon club client, three ways |

## How to use a guide

1. Open the unit's task file in the course repo and read it first.
2. Open the guide for that unit. Work down it in order. Each item says where it goes and what to put there.
3. When the guide gives facts, you write the sentences. When it gives an exact string (a title, a caption, an error message), use it as written.
4. Check the "Done when" list at the bottom before you push.

## Pictures

Use your own Switch screenshots (capture button > Album > Send to Smartphone) or phone photos of things you own. The guides include the credit line to add. Do not save pictures from Google Images into a public repo.

## Privacy

The site is public. First name only, the fake `example.com` email, and the 555 phone number from the task. No last name, school email, or address.
